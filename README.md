# Rhynchospora LTR Retrotransposons

Comparative annotation and analysis of complete and non-complete LTR retrotransposons across 20 holocentric Rhynchospora genomes.

## Overview

This repository contains annotation files, TE libraries, and summary tables associated with the manuscript:

> "Diversity of complete and non-complete LTR-retrotransposons in holocentric genomes of Rhynchospora (Cyperaceae)"

The dataset includes:
- Complete and fragmented LTR retrotransposons
- Non-autonomous elements (LARDs, TRIMs, and TR-GAGs)
- Comparative abundance tables
- Species-specific TE libraries
- Curated GFF3 annotations

## Repository structure

### 1_metadata
Metadata tables for species and genome assemblies.

### 2_annotations
GFF3 annotations of:
- LTR retrotransposons
- LARD elements
- TRIM elements
- TR-GAG domains

Both global and species-specific annotation files are provided when available.

### 3_TE_libraries
FASTA/FAA libraries of annotated elements:
- Complete LTR retrotransposons
- Non-autonomous elements
- TR-GAG protein domain sequences

### 4_tables
Summary tables generated during comparative analyses:
- TE abundance
- TE annotation catalogues
- LTR size datasets

## Notes

- Species names follow manuscript nomenclature.
- Some global files were omitted due to GitHub file size limitations.
- Species-specific datasets are prioritized for reproducibility and reviewer access.
